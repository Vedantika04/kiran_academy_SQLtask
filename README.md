# kiran_academy_SQLtask

This repository contains SQL practical tasks based on DDL, DML and DQL commands.

## Tasks

### Task 1 – SQL DDL
- Database and table creation
- Table structure modification
- Constraints and related SQL operations

### Task 2 – SQL DML
- INSERT operations
- UPDATE operations
- DELETE operations
- Working with table records

### Task 3 – SQL DQL
- SELECT queries
- WHERE conditions
- Sorting and filtering data
- Aggregate functions and other SQL queries

## Tools Used

- MySQL
- MySQL Workbench

## Repository Structure

- `Task-1/` – Task 1 SQL file and question PDF
- `Task-2/` – Task 2 SQL file and question PDF
- `Task-3/` – Task 3 SQL file and question PDF
